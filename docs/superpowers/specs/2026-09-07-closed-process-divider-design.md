# 结束流程分隔样式设计

## 目标

提升秋招投递总览中“进行中”和“已结束”两类记录的视觉区分，同时保持表格简洁。

## 设计

- 在最后一条进行中记录与第一条已结束记录之间插入一整行空白分隔行。
- 分隔行使用浅灰色填充，不放置任何文字，行高低于普通数据行。
- 已结束记录继续沉底，并保留当前状态颜色。
- 移除已结束记录所有单元格字体的删除线。
- 自动筛选范围覆盖进行中记录、分隔行和已结束记录。

## 保持不变

- 不修改公司、岗位、日期、地点、状态、备注和链接内容。
- 不修改现有数据行顺序，除插入分隔行造成的整体下移外。
- 不修改公司总数、工作表结构、列宽及已有合并单元格。

## 验证标准

- 进行中记录下方存在且仅存在一行浅灰色空白行。
- 所有已结束记录均位于分隔行下方。
- 所有已结束记录无删除线。
- 原有单元格值、超链接、非删除线样式、合并关系及统计值保持不变。
